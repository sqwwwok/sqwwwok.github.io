今日 Product Hunt 热榜（对应太平洋时间 2026-09-13 日榜）由「个人上下文 / 本地隐私算力」与「编码模型性价比」领跑：榜首 Resurf 把灵感与资料收成可交给 AI 的个人上下文库；Perplexity Hybrid Compute 把云端研究与 Mac 本地隐私任务拆开跑；Cognition 的 SWE-2 则强调接近前沿能力但更低推理成本。中段偏创作者与增长工具：带自动变焦的录屏 ScreenCursor、无账号 Notion 剪藏 Clipwise、AI 搜索可见度 Visiby。下半场是日式墨色 UI 套件 SHIUI、观众票选演示频道 DemoTV、本地会议笔记 Epilude Notetaker，以及 Windows 上「两下就写好」的 GhostWriter by MyHandler。票数来自 hunted.space 日榜快照（Resurf 约 224 票居首），排名仍可能微调。

## 1. [Resurf](https://www.producthunt.com/products/resurf-2) · [官网](https://resurf.so/)

**标语**：A Personal Context Library for Mac

**背景**  
Resurf（作者 Deep，设计工程师）定位为个人上下文库：快速保存笔记、链接、PDF、图片、视频与语音备忘，再用 spaces / tags / stacks 整理；可在应用内向资料库提问，或通过 MCP / CLI 把同一批上下文交给外部 AI 工具。公开材料强调 Mac / iPhone / iPad 原生、本地存储、可选私有 iCloud 同步；Mac 可免费试用，iOS 免费，Mac 无限用量为一次性购买。抓取时约 **224** 票、约 **15** 评，日榜第 1。

**产品要解决的问题**  
灵感、文章与截图散落在多个 App，事后难找回，也很难把「自己攒下的材料」稳定地喂给 AI 工作流。

**产品市场分析**  
目标为需要长期积累参考资料的设计、研究与知识工作者。竞品为通用笔记库、稍后读与仅云端的第二大脑。差异化叙事是「本地优先的上下文库 + MCP/CLI 外接 AI」；变现以 Mac 一次性买断为主（以官网为准）。

**产品上下游**  
上游：各 App 中的笔记、链接、文件与语音。下游：可检索的个人库，以及经 MCP/CLI 输出给写作/编程 Agent 的上下文。

## 2. [Perplexity Hybrid Compute](https://www.producthunt.com/products/perplexity-ai) · [介绍](https://www.perplexity.ai/hub/blog/introducing-hybrid-compute-on-mac)

**标语**：Splitting AI tasks: Cloud for research, Mac for privacy

**背景**  
Perplexity Hybrid Compute 是 Perplexity Computer（Mac）上的混合算力能力：同一任务拆到云端与本机——网页研究与强推理走云端模型，触及私有文件的步骤由本地模型处理；设备上的 Privacy Gate 可在敏感信息离机前遮蔽、拦截或征求确认。公开材料称面向 Pro / Max / Enterprise，需 Apple silicon、macOS 15+、至少 24GB 统一内存，并提供多款本地模型一键安装。官网博文在本环境偶发访问限制，细节主要依据 hunted.space / 公开报道。抓取时约 **191** 票、约 **2** 评，日榜第 2。

**产品要解决的问题**  
用户既想用前沿云模型做研究，又不想把客户文件、凭证等敏感内容整包上传。

**产品市场分析**  
目标为高配 Mac 上的专业用户与企业订阅户。竞品为纯云 Agent、纯本地 LLM 客户端与其它桌面「Computer」类产品。差异化叙事是「单任务云+端协同 + 隐私闸门」；绑定现有付费档。

**产品上下游**  
上游：本机受保护文件、云端检索/规划模型、可选 iPhone 远程触发。下游：在隐私约束下完成的研究与文件处理结果，回到用户工作流。

## 3. [Cognition's SWE-2](https://www.producthunt.com/products/cognition-s-swe-2) · [博客](https://cognition.com/blog/swe-2)

**标语**：Cognition's coding model, 64% cheaper than Fable 5.1

**背景**  
SWE-2 是 Cognition 新一代编码模型：在 Kimi K3 上做强化学习后训练，把运行成本直接写入奖励，并一次训练多个努力档位。公开基准称 FrontierCode 1.1 Main 约 50.0%，接近 Fable 5.1 且成本约低 64%；相对 SWE-1.7 称回合更少、更便宜。现已进入 Devin Desktop 与 CLI，并逐步推向 Web / Fusion。抓取时约 **156** 票、约 **2** 评，日榜第 3。

**产品要解决的问题**  
编码 Agent 变强时常伴随更高 token 账单与过度探索；团队需要接近前沿、但单位任务成本可控的模型。

**产品市场分析**  
目标为大规模使用 Devin / 编码 Agent 的工程团队。竞品为其它前沿编码模型与通用大模型的 coding 档。差异化叙事是「成本-能力帕累托」；通过 Devin 产品线变现（以官网为准）。

**产品上下游**  
上游：代码库、终端环境、用户任务与评测基准。下游：Devin Desktop/CLI 中的补丁、测试与代理回合，供开发者审阅合并。

## 4. [ScreenCursor](https://www.producthunt.com/products/screencursor) · [官网](https://screencursor.com/)

**标语**：Screen recorder with auto zoom effects

**背景**  
ScreenCursor 是 Chrome 扩展录屏工具：录制时跟踪光标点击/拖拽/按键，结束后自动生成带运镜变焦的成片，并可再手动调整每个 zoom；强调本地处理、无账号、无上传、无水印，Windows / Mac / Linux 只要有 Chrome 即可。公开报价约 $49 买断（PH 期有折扣码叙事）。抓取时约 **152** 票、约 **10** 评，日榜第 4。

**产品要解决的问题**  
产品演示录屏若要「跟手变焦」往往依赖 Mac 独占工具或后期剪辑；跨平台用户缺少安装成本低的替代。

**产品市场分析**  
目标为做教程/Demo 的独立开发者与市场人员，尤其是 Windows/Linux。竞品为 Screen Studio、其它自动 zoom 录屏与通用剪辑软件。差异化叙事是「Chrome 扩展 + 本地成片 + 买断」；以一次性授权为主。

**产品上下游**  
上游：浏览器标签或整屏画面、光标与键盘事件。下游：可导出的演示视频，进入文档、PH/官网与社媒分发。

## 5. [Clipwise](https://www.producthunt.com/products/clipwise-notion-web-clipper) · [Chrome 商店](https://chromewebstore.google.com/detail/clipwise-%E2%80%94-web-clipper-fo/fjgllpbhbnjdkhgmokagglhkahngmjki)

**标语**：Save any page to Notion

**背景**  
Clipwise 是面向 Notion 的浏览器剪藏扩展：用用户自己的 Notion integration 一次粘贴连接后，把完整网页（含代码块等）存进指定 database，保存前可填写属性，并记住上次 database；作者强调无 Clipwise 账号、无其服务器中转，内容直达用户 Notion，且宣称完全免费。抓取时约 **120** 票、约 **4** 评，日榜第 5。

**产品要解决的问题**  
许多 Notion 剪藏要求第三方账号或同步不稳，且常只存半页；用户只想「打开页面 → 填属性 → 进库」。

**产品市场分析**  
目标为以 Notion 为知识库的重度剪藏用户。竞品为官方 Web Clipper、其它 Notion 剪藏与稍后读。差异化叙事是「无中间账号 + 全文剪藏 + 保存前填属性」；公开材料以免费为主。

**产品上下游**  
上游：当前网页 DOM/正文与用户 Notion integration。下游：Notion database 中的结构化页面，供后续阅读与 AI 问答。

## 6. [Visiby](https://www.producthunt.com/products/visiby) · [官网](https://visiby.net/)

**标语**：Track and grow your visibility across AI search

**背景**  
Visiby 帮助品牌衡量并提升在 ChatGPT、Perplexity、Gemini、Google AI Overviews 等 AI 搜索中的可见度：跟踪提及、推荐与引用，对比竞品谁被点名，并给出可执行的优化机会。官网叙事强调面向营销团队的「AI 搜索可见度层」。抓取时约 **116** 票、约 **6** 评，日榜第 6。

**产品要解决的问题**

**产品市场分析**  
目标为关注 AEO/GEO 的营销与增长团队。竞品为新兴 AI 可见度监测与传统 SEO 套件的扩展模块。差异化叙事是「跨引擎提及/引用监测 + 行动建议」；具体套餐以官网为准。

**产品上下游**  
上游：品牌词/提示词集、各 AI 引擎回答与引用。下游：可见度报表与内容/结构化改造清单，供内容与 SEO 团队执行。

## 9. [Epilude Notetaker](https://www.producthunt.com/products/epilude) · [官网](https://www.epilude.com/)

**标语**：100% private meeting notes

**背景**  
Epilude Notetaker 是 Epilude（Mac 语音生产力套件）的会议笔记能力：不在会议里插入 bot，而是在本机录制；结束后生成转写、可编辑摘要与带负责人/期限的行动项，并按会议类型调整笔记结构，笔记可存为用户拥有的 Markdown。公开材料强调本地模型（如 EP-1）路径，使音频与摘要不必离开 Mac（具体模式以官网设置为准）。抓取时约 **97** 票、约 **6** 评，日榜第 9。

**产品要解决的问题**  
云端会议助手方便，但把通话内容交给第三方模型；用户想边开会边专注，又要私密、可导出的纪要。

**产品市场分析**  
目标为隐私敏感的 Mac 知识工作者。竞品为 Otter、Fireflies 等 bot 入会工具与其它本地转写 App。差异化叙事是「无 bot 入会 + 本地处理 + Markdown 所有权」；与 Epilude 订阅/买断档绑定（以官网为准）。

**产品上下游**  
上游：本机麦克风与会议放音、本地/云端转写模型。下游：Markdown 纪要与待办，进入笔记库或任务系统。

## 10. [GhostWriter by MyHandler](https://www.producthunt.com/products/ghostwriter-by-myhandler) · [官网](https://myhandler.ai/ghostwriter)

**标语**：Two taps and it's already written

**背景**  
GhostWriter 是 MyHandler（Windows 本地优先 AI）的写作功能：在任意应用文本框双击 Left Ctrl，基于屏幕上的线程、日历、文件与过往会议（加密索引在本机）起草回复，并匹配对该联系人的语气与落款；强调只写入输入框、产品内没有「代发」路径。公开材料称免费额度起步，面向 Windows 10/11。抓取时约 **97** 票、约 **18** 评，日榜第 10。

**产品要解决的问题**  
通用聊天式写作要反复粘贴上下文；用户需要的是「看一眼屏幕就知道该回什么」，且不能误发送。

**产品市场分析**  
目标为大量处理邮件/消息的 Windows 用户。竞品为浏览器侧边栏写作助手、邮件客户端 AI 与其它本地 Agent。差异化叙事是「屏幕上下文 + 本地保险库 + 绝不代发」；Freemium / 折扣码叙事以页面为准。

**产品上下游**  
上游：前台窗口文本、本机日历/文件/会议索引。下游：落在输入框中的草稿，由用户编辑后自行发送。
