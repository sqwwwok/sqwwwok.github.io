## 1. [Hemory](https://www.producthunt.com/products/hemory) · [官网](https://hemory.com)

**标语**：Keep listening. Searchable memory for your AI agents.

**背景**  
Hemory（Hear + Memory）由 Yingqi 团队推出：不是会议纪要工具，而是在已有 iPhone / Android / Apple Watch 上持续聆听，把一天按活动自动切成带说话人标注的「时刻」，沉淀为私有可搜索记忆；再经 MCP 接到 Claude、Codex、Cursor 等 Agent，让模型能跨天检索「昨天听到什么」「本月定价讨论」一类问题。公开称默认不长期存云端音频、处理后丢弃，记忆以文本形式保存；套餐含试用与按聆听时长计费档位（Starter / Pro / Max），仅检测到的语音计入额度。抓取时约 **319** 票、约 **69** 评，日榜第 1。

**产品要解决的问题**  
会议与日常对话大量流失：忘开录、多段合并、跨日拼上下文仍靠人肉；通用会议摘要又难直接变成 Agent 可调用的长期记忆。

**产品市场分析**  
目标为高频开会、需要把口述上下文交给编码 / 写作 Agent 的知识工作者。竞品为 Otter / Fireflies 等会议转录、以及各家「记忆」插件。差异化叙事是「全天聆听 + 时刻切分 + MCP 记忆源」；商业化为订阅式聆听额度，自托管标注即将推出。

**产品上下游**  
上游：手机 / 手表麦克风、语音活动检测与转录管线、MCP 客户端（Claude Code / Codex / Cursor 等）。下游：可搜索记忆、Agent 生成的周报 / PRD / 日记等文档，以及后续任务执行。

## 2. [Eclatira](https://www.producthunt.com/products/eclatira) · [官网](https://eclatira.com)

**标语**：Conversational Video Agent That Plugs Into Any Stack

**背景**  
Eclatira 面向开发者，提供可嵌入任意应用的实时对话式视频 AI 引擎：原生语音对语音、摄像头 / 屏幕实时视觉，以及通过自定义 API、MCP 与声称的 3,000+ 应用集成执行动作。定位是少拼多条管线，把「说、看、做」合在一个对话引擎里；公开页标 Free Options，并有首三个月半价促销。讨论区涉及延迟、多模态状态同步、动作护栏与隐私（称当前不存直播流）。抓取时约 **288** 票、约 **58** 评，日榜第 2。

**产品要解决的问题**  
团队要做「会看屏、能说话、还能改 CRM」的 Agent 时，往往要自建语音、视觉与工具调用基础设施，延迟与一致性成本高。

**产品市场分析**  
目标为 AI 助手、客服、互动副驾驶与视频优先产品团队。竞品为 LiveKit / Agora 等实时媒体栈加自研 LLM 编排，或单一模态语音 Agent API。差异化叙事是「即插即用的多模态视频 Agent + 动作执行」；自托管暂不可用，数据区域控制称在路线图上。

**产品上下游**  
上游：应用侧摄像头 / 屏幕流、用户语音、厂商 LLM、第三方集成认证。下游：实时对话会话、对外部 SaaS / 内部 API 的动作结果，以及嵌入宿主产品的交互体验。

## 3. [Chit](https://www.producthunt.com/posts/chit-2) · [官网](https://chit.zopcloud.zop.dev/)

**标语**：A printed receipt of your day in Claude Code

**背景**  
Chit 是约 777 KB 的 macOS 菜单栏应用 + CLI：只读本地 `~/.claude/projects` 中 Claude Code 已写入的 transcript，按项目汇总当天做了什么，输出可贴进 standup / 工时表的「小票」；不展示用户提示词，无网络代码、无账号。免费可看今日；一次性约 $12 解锁历史日、周视图与仪表盘。作者强调未公证下载可能被系统提示，并提供终端安装脚本。抓取时约 **189** 票、约 **14** 评，日榜第 3。

**产品要解决的问题**  
整天在 Claude Code 里干活，傍晚却说不清上午改了什么；会话日志对 standup / 客户更新不够「像工作产出」。

**产品市场分析**  
目标为重度 Claude Code 用户与需要日结汇报的独立开发者 / 顾问。竞品为手动记笔记、Bench / Claudebin 等会话存档分享工具。差异化叙事是「纯本地、零网络、小票格式」；一次性买断而非订阅。

**产品上下游**  
上游：本机 Claude Code transcript 与会话标题 / 改动文件名。下游：剪贴板中的日结 / 项目小结、可 pipe 进工时系统的 CLI 输出；不写回 `~/.claude`。

## 4. [MakerMap](https://www.producthunt.com/products/makermap) · [官网](https://makermap.lol)

**标语**：A living map of makers and what they’re building

**背景**  
MakerMap（Martijn Verbove）把 maker 世界做成可浏览地图：宣称可发现 4,000+ makers 与产品，按 niche、地点、兴趣或「正在做什么」搜索，查看 live profile 并找值得见面的人；用 X 登录加入地图。列表免费，可选付费支持或购买 Ships / Yachts 增加曝光。抓取时约 **159** 票、约 **16** 评，日榜第 4。

**产品要解决的问题**  
独立开发者与创作者分散在社交平台，目录型站点易过期，线下与同城 / 同赛道连接成本高。

**产品市场分析**  
目标为 indie maker、小型产品团队与寻找同行的 builder。竞品为 Twitter/X 列表、Product Hunt 关注关系、传统创业者目录。差异化叙事是「地图 UX + 按在建事物检索」；变现靠可选赞助位 / 曝光道具，登录依赖 X。

**产品上下游**  
上游：maker 自填档案、X 身份、地理位置与产品信息。下游：可跳转的发现与联系路径、曝光位，以及围绕地图形成的社区互动。

## 5. [Paragraph Notes](https://www.producthunt.com/products/paragraph-notes) · [官网](https://paragraphnotes.md)

**标语**：A private Markdown notes app for Mac

**背景**  
Paragraph Notes 是面向 Mac 的隐私向 Markdown 笔记：纯文本、无干扰编辑；声称零数据采集、永不联网，笔记以开放可移植格式本地存储。免费最多 20 条笔记，Pro 为一次性应用内购解锁无限量；可通过设置把数据库指到 iCloud Drive 文件夹，由用户自行同步多机。抓取时约 **142** 票、约 **4** 评，日榜第 5。

**产品要解决的问题**  
云笔记默认上传带来隐私与锁定担忧；部分用户只想要本地、简单、可带走的 Markdown，而不要同步订阅。

**产品市场分析**  
目标为重视隐私的 Mac 写作者与开发者。竞品为 Obsidian / Bear / Apple Notes / iA Writer。差异化叙事是「永不联网的本地 Markdown + 一次性买断」；多机同步依赖用户自管文件夹，而非产品侧云服务。

**产品上下游**  
上游：用户键入的 Markdown、本地数据库路径（可选 iCloud Drive）。下游：本地笔记文件与可迁移的数据库；无云端协作下游。

## 6. [GoodSocials](https://www.producthunt.com/products/goodsocials) · [官网](https://goodsocials.co)

**标语**：AI social media manager for LinkedIn. Only authentic content

**背景**  
GoodSocials（Pavel / GoodLads，曾做 TimeTuna）定位「只发基于真实数据或深度研究的 LinkedIn 内容」：从 GitHub PR、日历、分析与研究等来源起草，经看板审批后排期近乎每日发布，并强调反「AI 腔」。官网对比人工社媒经理，标价约 $100/月量级；上架有三个月 33% 折扣码宣传。当前仅 LinkedIn，Instagram / X 称后续。抓取时约 **123** 票、约 **9** 评，日榜第 6。

**产品要解决的问题**  
创始人想稳定更新 LinkedIn，但手写耗时；通用 AI 文案又易同质化、像硬广，损害信任。

**产品市场分析**  
目标为需要 inbound 的创始人、顾问、运营与小型机构。竞品为 Buffer / Hootsuite 调度器、通用 ChatGPT 写帖、人工社媒经理。差异化叙事是「数据 / 研究驱动 + 人工审批看板 + 语气规则沉淀」；付费订阅，代理计划亦有提及。

**产品上下游**  
上游：GitHub、分析工具、日历等集成数据与深度研究输入、用户修订规则。下游：经审批的 LinkedIn 帖文与配图、排期发布，以及可复用的语气规则库。

## 7. [Fewer](https://www.producthunt.com/products/fewer)

**标语**：The launcher that counts how often you pick up your phone

**背景**  
Fewer（Ali Sarac）是 Android 启动器：主屏突出「今天拿起几次 / 其中多少次一无所获」、当日任务，以及六个实际常用工具；对 Instagram / YouTube 等「时间陷阱」在打开前插入短暂停顿并记录意图时长，但不强制锁定。无服务器、无账号、无广告与分析；Usage access 可选。免费可用，一次性 Fewer Pro（含 14 天全功能试用）解锁周计划、时段预算与七日摘要。官网链接未在列表页单独展开，下载以 Product Hunt 产品页为准。抓取时约 **113** 票、约 **8** 评，日榜第 7。

**产品要解决的问题**  
屏幕时间数字往往不改变行为；真正刺痛的是无意义的反复拿起，而现有工具又难把计数放在「每次回家屏就看见」的位置。

**产品市场分析**  
目标为想减少无意识解锁的 Android 用户。竞品为其他数字健康启动器、系统 Digital Wellbeing。差异化叙事是「pickup 计数 + 极简主屏 + 本地零账户」；因启动器能力限制，作者明确无 iOS 计划。

**产品上下游**  
上游：本机拿起 / 解锁信号与可选用量访问、用户设定的时间陷阱与周目标。下游：主屏反馈数字、暂停后的意图对照，以及 Pro 侧周摘要；数据不出设备。

## 8. [Psst](https://www.producthunt.com/products/psst-3)

**标语**：A shared shopping list that remembers what things cost

**背景**  
Psst 是共享购物清单：拍照小票得到结构化行项目（含裁切证据），并记住该商品上次价格与购买地点；强调不确定时不强行对比，且按单价而非行总额比较，避免「买 2kg 当涨价」。协作（邀请、角色、评论、活动流、在线状态）在免费层；支持离线后同步；iOS / Android / Web。公开促销「3 months Pro for $0.99」。独立官网 URL 未在抓取页明确展示，以 Product Hunt 产品页为准。抓取时约 **106** 票、约 **10** 评，日榜第 8。

**产品要解决的问题**  
家庭共享清单常退化为截图或单人待办硬加分享；另方面，记不清某物在哪家店更便宜，且单位不一致时容易误判涨价。

**产品市场分析**  
目标为共同采购的家庭 / 室友。竞品为 AnyList / Bring! / 笔记与聊天截图。差异化叙事是「协作原生 + 小票价史 + 谨慎的单价比较」；免费协作 + 低价 Pro 促销。

**产品上下游**  
上游：用户清单编辑、小票照片与 OCR / 结构化解析。下游：共享清单状态、价史提示与门店记忆，以及超市现场的离线可用列表。

## 9. [Kleanly](https://www.producthunt.com/products/kleanly) · [购买页](https://haidernawaz8.gumroad.com/l/tiyffv)

**标语**：One tap in the notch locks your keyboard and trackpad

**背景**  
Kleanly（Haider Nawaz）第二次上架：住在 MacBook 刘海里，一点锁定键盘与触控板，便于擦机身同时视频继续播放；小孩乱拍键也不会输入。双击触控板解锁。相对首发新增刘海控件、应用内更新、自行迁移授权，以及无刘海屏上的小标签。付费产品，经 Gumroad 分发。抓取时约 **105** 票、约 **26** 评，日榜第 9。

**产品要解决的问题**  
擦 Mac 键盘时误触输入 / 切应用；带娃看动画时键盘成玩具；系统锁屏又会打断正在播放的内容。

**产品市场分析**  
目标为需要清洁键盘或带幼儿的 Mac 用户。竞品为临时关闭键盘的脚本、CleanMyMac 类工具中的清洁模式。差异化叙事是「刘海一触 + 屏不灭」；一次性付费，覆盖有 / 无刘海机型。

**产品上下游**  
上游：刘海 / 顶部标签点击与触控板双击手势。下游：键鼠锁定状态、可选暗色清洁遮罩，以及继续播放的屏幕内容。

## 10. [Lisen](https://www.producthunt.com/products/lisen) · [Chrome 应用商店](https://chromewebstore.google.com/detail/lisen-free-read-aloud-wit/jjglbebakkebkafjilbfnejmgpdphbhp)

**标语**：Free Read Aloud with Cartesia Voices

**背景**  
Lisen 是 Chrome 扩展：用用户已有的 Cartesia 音色为任意文章朗读，作者称不再叠加一层订阅；讨论中提到无中间服务器、支持 WAV 导出，音色自然度依赖 Cartesia。免费。抓取时约 **105** 票、约 **20** 评，日榜第 10（与 Kleanly 票数接近）。

**产品要解决的问题**  
长文「用耳朵读」常被浏览器自带语音质量或额外 TTS 订阅卡住；已有 Cartesia 账号的用户不想再买一层朗读服务。

**产品市场分析**  
目标为阅读量大的知识工作者与 Cartesia 用户。竞品为浏览器原生朗读、Speechify、其他 TTS 扩展。差异化叙事是「直接复用 Cartesia 音色 + 免费、无中间层」；变现未在列表页展开（作者评论称暂无收费动机）。

**产品上下游**  
上游：网页正文抽取、用户的 Cartesia 语音配置 / API。下游：浏览器内朗读流与可选 WAV 导出文件。
